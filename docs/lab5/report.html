1. Описание модели

Выбран процесс SIR: узел сети может быть в состоянии S (восприимчив), I (заражен), R (выздоровел/иммунен).

S->I с вероятностью beta по каждому ребру; I->R с вероятностью gamma на каждом шаге.

Типы сетей:

  • Erdos-Renyi: случайная сеть с параметром плотности связи p.
  • Scale-Free (Barabasi-Albert): сеть с хабами, параметр m (число новых связей при добавлении узла).

Параметры процесса

ПараметрЗначениеСмысл

Входные параметры экспериментов

  • Плотность связей ER: 0.01, 0.02, 0.03, 0.05, 0.08.
  • Параметр m в scale-free: 1, 2, 3, 4.
  • Вероятность передачи beta: от 0.04 до 0.22.
  • Начальное число зараженных: 1, 3, 5, 10, 20.
