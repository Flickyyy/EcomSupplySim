1 Описание модели

Объект моделирования: логистическая система e-commerce доставки с возвратами. Используется модель из ПР1-3: поток заказов, сборка, доставка, возвратная логистика.

Входные параметры оптимизации

  • NCouriers — число курьеров (4..24, шаг 2).
  • NStores — число магазинов/складов (3..6).
  • SlotsPerStore — число параллельных слотов сборки на магазин (2..5).

Выходные показатели

  • Delivered %, SLA breach %, Avg delivery (мин).
  • Загрузка курьеров и сборки.
  • Структура статусов (Cancelled %, Disposed %).
  • Интегральная стоимость по целевой функции.

2 Целевая функция и ограничения

Цель: минимизировать суммарные дневные затраты
TotalCost = ResourceCost + SLA penalty + Cancel penalty + Dispose penalty

Ресурсная часть: курьеры + склады + слоты сборки. Штрафы: за SLA-нарушения, отмены и утилизацию.
