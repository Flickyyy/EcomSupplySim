1 Описание модели

EcomSupplySim — дискретно-событийная имитационная модель цепочки поставок интернет-магазина. Модель охватывает полный цикл обработки заказа: генерация заявок (пуассоновский поток с часовой интенсивностью), сборка на складе, назначение курьера, доставка клиенту (с учётом трафика и поломок), возвраты и утилизация.

2 Верификация модели

Верификация выполнена через 7 тестовых проверок: сравнение с аналитическими расчётами, проверка баланса потоков и монотонности поведения.

#ТестОписаниеОжиданиеФактРезультат

Пояснения к тестам

  • Баланс заказов — каждый заказ заканчивается одним из 4 статусов: Delivered, Cancelled, Restocked, Disposed. Сумма должна равняться общему числу заказов.
  • Среднее заказов/день — аналитический расчёт: сумма часовых λ за 24 часа при LambdaMult=1 даёт ∑λ(h)≈153 заказа/день.
  • Целостность снимков — сумма day.Orders по всем дням должна совпадать с TotalOrders.
  • Баланс каждого дня — D+C+R+Disp = Orders для каждого отдельного дня.
  • Идеальные условия — при 50 курьерах, 10 складах, без дефектов и возвратов → ≈100% доставки.
  • Загрузка сборки — сравнение с формулой: Nord·μasm/(Nst·Ksl·1440)·100%.
  • Монотонность — увеличение числа курьеров должно приводить к росту % доставки.

3 Статистическая обработка результатов

Для каждого сценария выполнено моделирование с достаточным объёмом данных (>1 000 000 заказов), собрана подневная статистика и рассчитаны: среднее, дисперсия, стандартное отклонение, 95%-й доверительный интервал (±1.96·σ/√n), правило 3σ.
